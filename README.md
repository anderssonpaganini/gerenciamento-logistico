# Gerenciamento Logístico — APO (UNIPAR EAD)

Aplicação web desenvolvida em **PHP**, **HTML**, **CSS (Bootstrap)** e **JavaScript** para gerenciamento logístico, executada localmente com **XAMPP**.

## Funcionalidades
- **Produtos:** cadastro e edição de itens.
- **Endereços:** cadastro e edição de endereços de origem e destino.
- **Transportadores:** cadastro e edição de transportadores.
- **Fretes:** vinculação de um transportador a múltiplos produtos e rotas, além de consulta/relatório por dia.

## Como executar localmente
1. Coloque a pasta do projeto dentro de `htdocs` no **XAMPP** (`C:\xampp\htdocs\gerenciamento-logistico`).
2. Inicie o **Apache** no painel do XAMPP.
3. Acesse `http://localhost/gerenciamento-logistico/` no navegador.
